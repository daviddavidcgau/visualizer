Blister App - Offline Streamlit Desktop Tool
-------------------------------------------
1. Install dependencies:
   pip install streamlit matplotlib pillow pandas

2. Run the app via launcher:
   Double-click 'launcher.exe' (after compiling with PyInstaller) or run:
   python launcher.py

3. Place your image files in:
   - 'assets/img_landscape.png'
   - 'assets/img_portrait.png'
   - 'machine_images/{model_name}.jpg'
